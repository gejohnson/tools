YouTube → MP3 podcast feed builder (frontend prototype)

This is a single-file static app designed for GitHub Pages. It builds a valid podcast RSS feed, but it expects a backend worker to do the actual YouTube → MP3 conversion.

Why a backend is needed

  • Browsers cannot reliably fetch and decode YouTube media streams because of CORS, signature/cipher logic, and anti-bot protections.
  • ffmpeg.wasm can transcode in-browser, but you still need direct media bytes first (the hard part for YouTube links).
  • A tiny server/worker running yt-dlp + ffmpeg is the practical approach.
